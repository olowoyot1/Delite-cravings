# Delite Cravings

Daily sales, stock and product price calculator for Delite Cravings.

## Features
- Drinks, Snacks and Bread categories
- Opening stock + daily additions + closing stock
- Automatic quantity sold and sales calculation
- Editable unit prices
- Product master list
- Excel (.xlsx/.xls) and CSV import
- Excel template download
- CSV daily sales export
- Browser localStorage persistence
- Responsive design
- Static/Vercel-ready deployment with no server required

## Excel columns
Category, Product, Unit Price, Opening Stock, SKU

## Formula
Qty Sold = Opening Stock + Additions - Closing Stock  
Sales = Qty Sold × Unit Selling Price
